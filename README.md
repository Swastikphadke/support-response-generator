# Support Response Generator

[![Built with askThili](https://msrit.ask.thili.ai/api/v1/public/projects/35rtapa94n/badge.svg)](https://msrit.ask.thili.ai/b/35rtapa94n)

This CLI tool, designed for retail customer support agents, leverages a next-word predictor to streamline response drafting. By analyzing a corpus of past support interactions, it offers intelligent suggestions, helping agents quickly and consistently address common customer queries.

## What you are building

**Goal.** You will build a command-line interface (CLI) tool that helps customer support agents draft responses by generating next-word suggestions based on past support interactions.

**Done when.** The tool successfully loads an anonymized corpus, implements an n-gram model with smoothing, generates coherent next-word suggestions for agent input, and provides a functional command-line interface for agents to use.

### Baseline and Model Limitations

The model uses a frequency-based n-gram approach with add-k (Laplace) smoothing. Its predictions are based on observed token sequences rather than semantic understanding.

A frequency-only next-token predictor would select the globally most frequent token regardless of the preceding context. The n-gram model improves on this approach by conditioning predictions on the preceding one or two tokens.

A formal held-out accuracy comparison against this baseline has not yet been conducted.

### Limitations

- The training corpus is small and consists of synthetic retail support responses.
- Predictions are limited to patterns represented in the training corpus.
- Greedy next-token selection can produce repetitive or generic responses.
- Unseen contexts may result in no continuation.
- The model does not understand customer intent or generate semantically novel responses.
- Performance and generalisation on real-world customer support data have not been benchmarked.
